# Walmart Weekly Sales Forecasting

This project analyzes and forecasts Walmart weekly sales using time series techniques and machine learning models.

## Project Structure
- `data/` – dataset used for analysis
- `notebooks/` – Jupyter notebooks with data exploration and modeling
- `requirements.txt` – project dependencies

## Objectives
- Understand seasonal patterns in retail sales
- Analyze the effect of holidays on weekly sales
- Compare forecasting models

## Tools
- Python
- Pandas
- Matplotlib
- Scikit-learn
